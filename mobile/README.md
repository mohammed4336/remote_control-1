# تطبيق تحكم بعيد (Android + iOS)

هذا مجلد التطبيق الأصلي المبني باستخدام Capacitor. يحافظ على الموقع الحالي كواجهة واحدة مشتركة، ويحمّله داخل غلاف تطبيق أصلي آمن عبر HTTPS.

## ما الذي يعمل الآن؟
- نفس صفحة الدخول والحسابات والأجهزة المرتبطة الموجودة في الموقع.
- نفس اتصال WebSocket والتحكم الحالي، دون تعديل `agent.exe` أو السيرفر.
- اسم التطبيق ومعرّفه الأصليان: `تحكم بعيد` / `com.akira.remotecontrol`.

## البناء المحلي
من هذا المجلد:
```bash
npm install
npx cap add android
npx cap add ios
npx cap sync
```

افتح Android Studio أو Xcode لإكمال البناء والتوقيع.

## ملاحظات الإصدار
- إعداد الخادم الحالي يجعل التطبيق يعتمد على اتصال الإنترنت وعلى توفر موقع Render.
- ملف Android الناتج من GitHub Actions هو APK تجريبي غير منشور على Google Play.
- بناء iOS يحتاج macOS وXcode. ملف المحاكي لا يثبت على iPhone؛ النشر على App Store أو التثبيت على جهاز حقيقي يتطلب توقيع Apple وحساب Apple Developer.
- قبل النشر العام، يلزم اختبار تسجيل الدخول، لوحة التحكم، الصوت، WebSocket، إيماءات اللمس، وسياسة الخصوصية على أجهزة فعلية.
